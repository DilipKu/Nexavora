## 🚦 Getting Started

### Prerequisites
- Node.js `v18.x` or higher
- npm `v9.x` or higher

### Installation

```bash
# Clone the repository
git clone https://github.com/DilipKu/Nexavora.git

# Install dependencies
npm install
```

### Local Development

Start the local development server at `http://localhost:4321`:

```bash
npm run dev
```

### Production Build

Build the optimized production static site in `dist/`:

```bash
npm run build
```

Preview the static build locally:

```bash
npm run preview
```
